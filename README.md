# БТС AI — умная подготовка к экзамену

PWA-приложение для подготовки к БТС (Ұлттық тестілеу): ИИ читает ваши материалы (PDF, DOCX, PPTX, XLSX, TXT, изображения) и делает **тесты, карточки и конспекты** с тремя уровнями сложности — без повторов и с адаптацией под ваши ошибки.

Полностью бесплатно: приложение статическое, своего сервера нет, работает как PWA (можно установить на телефон).

---

## Что умеет

| Возможность | Описание |
|---|---|
| 🧠 **ИИ-генератор** | Тесты, карточки и конспекты по вашим файлам. Один запрос — «Всё сразу». |
| 🅰🅱🅲 **Три уровня** | **A** — база (факты, термины, формулы). **B** — применение и расчёты. **C** — многошаговые задачи, всё самое сложное. Можно выбрать один уровень, смешанный набор или адаптивный. |
| 🚫 **Без повторов** | Каждый вопрос и карточка попадают в «Банк вопросов». В следующих генерациях они запрещены для ИИ и отсекаются локальной проверкой (точное совпадение + семантическое сходство). |
| 📚 **20–40 вопросов** | Сколько именно — на ползунке. Генерация идёт пакетами по 8 вопросов, чтобы не упираться в лимиты бесплатных моделей. |
| 📈 **Адаптивность** | ИИ видит ваш результат по каждому уровню и по темам, после чего сам решает пропорцию A/B/C и подсвечивает слабые места. |
| ➕ **Кнопка «+»** | Загрузка файлов: PDF (текстовый слой), DOCX, PPTX, XLSX/CSV, TXT/MD, PNG/JPG. Файлы парсятся прямо в браузере, текст уходит выбранному ИИ-провайдеру. |
| 🔐 **Вход через Google** | Google Identity Services. Данные каждого аккаунта хранятся отдельно. Гостевой режим — без регистрации. |
| ♻️ **Интервальное повторение** | Ошибки возвращаются через 10 минут → 1 день → 3 дня. |
| 🧮 **Калькулятор** | Научный калькулятор (DEG/RAD, тригонометрия, логарифмы, факториал). |
| ✍️ **Рисование по конспекту** | Слой для заметок поверх конспекта: карандаш, маркер, ластик, цвета. |
| 📴 **Offline/PWA** | Ставится на телефон, работает офлайн, данные — в IndexedDB + экспорт в JSON. |

## Бесплатные ИИ-провайдеры

Приложение не покупает и не продаёт ИИ. Вы выбираете провайдера в **Настройках**:

| Провайдер | Как получить | Нюансы |
|---|---|---|
| **Google Gemini** (по умолчанию) | бесплатный ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | free tier: ~15 запросов/мин, 1500/день. Умеет читать изображения. |
| **OpenRouter** (`*:free` модели) | ключ на [openrouter.ai/keys](https://openrouter.ai/keys) | модели с суффиксом `:free`. |
| **Локальный Ollama / LM Studio** | `ollama serve` на своём компьютере | полностью офлайн, трафик не расходуется. |
| **Локальный режим** | ничего | Без нейросети: вопросы и карточки собираются из вашего материала эвристически. Работает всегда. |

Ключ хранится только в вашем браузере (IndexedDB) и уходит исключительно выбранному провайдеру. Сервера приложения не существует — отсюда и «абсолютно бесплатно».

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
```

Стек: React 18 + TypeScript + Vite + Tailwind CSS, pdf.js (PDF), JSZip (DOCX/PPTX/XLSX), KaTeX (формулы). Зависимостей минимум, бэкенда нет.

## Как это сделано (важные решения)

- **Никакого сервера.** Всё, включая файлы, распознаётся в браузере; ключ ИИ хранится локально. Поэтому приложение бесплатно по определению.
- **Уровень C изолирован.** Для каждого уровня идёт отдельная серия запросов с явными правилами сложности, поэтому в тесте «только C» не может оказаться вопрос уровня A.
- **Дедупликация двумя слоями.** В промпт уходит список уже использованных вопросов (запрет), а на выходе — проверка по хэшу и семантическому сходству (Jaccard по токенам, порог 0.82).
- **Пакетная генерация.** По 8 вопросов за запрос: так укладывается в лимиты бесплатных моделей и не обрывается длинный ответ.
- **Адаптивная пропорция.** `C ≥ 75%` → 65% сложных; `B ≥ 60%` → 35% сложных; иначе — упор на закрепление.
